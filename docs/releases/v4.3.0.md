A much nicer ghapk for browsing builds and getting APKs onto your phone.

### What's new

- Browse repositories, branches, workflows and builds with a cleaner, more touch-friendly layout. Your last choices are remembered.
- Install starts with a plan, or you can just download. The new Downloads tab keeps track of background jobs and saved APKs.
- GitHub Release assets and APKs tucked inside nested ZIPs are supported too.
- There's a proper Settings tab, a persistent activity log, ASCII mode and customizable key bindings.
- Help now scrolls and wraps on smaller screens, and the Device tab has more useful details.

### Better and safer

- Downloads check GitHub's SHA-256 digest when one is available and can safely reuse validated cached files.
- Install checks are clearer about package names, signing keys, downgrades and matching version codes. A handoff isn't called a confirmed install unless it can be verified.
- Uninstalling is never automatic and needs explicit confirmation; it erases the app's data.
- Lots of fixes for phone navigation, overlays, cancellation, scrolling and installer handling. The old separate Artifacts pane and Settings popup have been replaced by the new layout.

Grab the binary for your platform below, or update with the installer. As always, `gh` needs to be installed and signed in. Hope you enjoy it!
